Numerical Approximation of Definite Integrals

Correct graphical interpretation of Riemann sums, Trapezoidal rule, and Simpson’s rule

📐 Riemann Sum (Left Endpoint)

The interval is divided into equal subintervals. Rectangles are drawn using the left-endpoint value of the function. All rectangles lie completely below the curve for an increasing function.

∫₀² x² dx ≈ Σ f(xᵢ) · Δx

📊 Trapezoidal Rule

In the trapezoidal rule, the top of each region is a straight line connecting two points on the curve. This gives a better approximation because the shape follows the curve more closely.

∫₀² x² dx ≈ (h/2)[f(x₀)+2f(x₁)+f(x₂)]

📈 Simpson’s Rule

Simpson’s Rule approximates the curve using parabolic arcs over pairs of subintervals. This gives extremely accurate results for smooth curves like polynomials.

∫₀² x² dx ≈ (h/3)[f(x₀)+4f(x₁)+f(x₂)]
